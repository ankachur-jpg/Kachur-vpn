# Kachur VPN

Персональный VPN-клиент для Android.

## Основные функции
- Подключение к собственному VPN-серверу
- Раздельная маршрутизация трафика
- Банки, Госуслуги и маркетплейсы без VPN
- Инвестиционные приложения без VPN
- Импорт JSON со списками IP-адресов
- Автоматическое обновление правил
- Ручное управление исключениями
- Диагностика соединения

## Статус

На главном экране можно импортировать локальный профиль AmneziaWG из файла `.conf`. Последний выбранный профиль сохраняется в зашифрованном виде с ключом Android Keystore. Сборка с официальным движком AmneziaWG различает запуск туннеля и подтверждённый движком handshake. Handshake и передачу трафика этой сборки ещё нужно проверить на физическом Android.

[Версии, сборка и обработка данных профиля](third_party/amneziawg/README.md).

## Исключения по IP

Откройте «Раздельная маршрутизация» → «IP-исключения». Импорт объединяет файл с уже сохранёнными правилами. Адреса приводятся к каноническому виду, повторяющиеся записи объединяются. Список можно искать и редактировать вручную.

Оба формата используют UTF-8.

```json
[{"hostname":"192.0.2.0/24","ip":""}]
```

```json
{"version":1,"bypass":["192.0.2.0/24","2001:db8::7"]}
```

В формате `hostname`/`ip` числовой `hostname` имеет приоритет. Если `hostname` пуст или содержит DNS-имя, можно указать числовой адрес в `ip`. Импорт выполняется целиком после проверки всех записей. В приложении сохраняются только нормализованные IP/CIDR.

IP-исключения применяются к маршрутам `AllowedIPs` профиля на уровне Android. Android 13 и новее использует `VpnService.Builder.excludeRoute()`. На Android 8–12 приложение вычисляет точный остаток маршрутов VPN. Если расчёт превышает лимит в 4096 маршрутов, приложение выдаёт ошибку и сохраняет текущее соединение. Доступ напрямую также зависит от сети устройства и политики Android, которая может запрещать трафик вне VPN.

Исключения приложений действуют вместе с правилами по IP. Применение новых правил на работающем VPN требует переподключения. Между остановкой и запуском есть короткий перерыв в работе VPN.

### Источники и обновление IP

В «IP-исключениях» можно открыть «Источники IP и автообновление», включить RIPEstat и добавить до восьми HTTPS-ссылок на JSON в одном из форматов выше. Источники включаются по выбору пользователя. Для автоматического обновления по умолчанию используется недельный интервал. Также доступны ежедневный и ручной режимы. Android назначает время запуска в зависимости от доступности сети и режима энергосбережения.

RIPEstat публикует ресурсы с кодом регистрации `RU` на основе статистики региональных интернет-регистраторов. Приложение объединяет смежные и вложенные CIDR без расширения подсетей и выбирает крупнейшие точные блоки IPv4 и IPv6 в пределах бюджета маршрутов. На Android 8–12 размер набора меньше из-за преобразования исключений в положительные маршруты. Код регистрации не гарантирует, что адрес используется в этой стране. [Документация RIPEstat](https://stat.ripe.net/docs/data-api/api-endpoints/country-resource-list)

В списке источников отображаются время последнего успешного обновления и число сохранённых префиксов. Приложение заменяет скачанные списки одним пакетом после проверки всех источников. Ошибка загрузки, пустые или некорректные данные, исключение целого семейства адресов и превышение лимита маршрутов сохраняют прошлые списки. Ручные исключения и импорт из файла хранятся отдельно.

Обновление сохраняет правила для следующего запуска туннеля. Активная VPN-сессия продолжает работать с исходным набором. Ко вновь сохранённым правилам применяется обычная проверка маршрутов выбранного профиля перед ручным переподключением.

## Уведомление и восстановление соединения

Foreground-служба показывает состояние VPN и кнопку отключения. Страна берётся из метки профиля. По умолчанию это «Германия». Метку можно изменить на главном экране после импорта. Приложение сохраняет метку локально для того же документа.

Счётчик времени начинается с подтверждённого handshake, а объём трафика берётся из AmneziaWG для текущего туннеля. Во время восстановления уведомление показывает ход переподключения. После окончательной ошибки краткое уведомление остаётся доступным в панели Android.

Foreground-уведомление использует канал «Состояние VPN». На Android 13 и новее для показа в панели нужно разрешить уведомления. Android 14 и новее позволяет пользователю смахнуть постоянное уведомление. Ручное отключение доступно и с главного экрана.

При потере интернета или смене доступной физической сети служба освобождает старый туннель. После восстановления проверенной Android сети она пробует подключиться до трёх раз. Общее время ожидания ограничено пятью минутами. Лимит попыток восстанавливается после минуты стабильного соединения. Ручное отключение отменяет восстановление. Во время перерыва VPN трафик использует обычную маршрутизацию Android. На смартфоне предстоит проверить переходы Wi‑Fi ↔ мобильная сеть, handshake, счётчики и прохождение трафика с настроенными исключениями.

## Запуск и ручное отключение

Автоподключение включено по умолчанию. После первичного импорта приложение использует локально сохранённый профиль при следующем открытии, проверяет разрешение `VpnService` и учитывает уже действующий VPN. Отключение из уведомления обновляет статус главного экрана и приостанавливает автоподключение. Его можно возобновить ручным подключением или повторным включением настройки.

## Ручные резервные копии

На экране «Резервные копии» задайте пароль и выберите место через системный интерфейс Android. Файл `.kvb` включает выбранный профиль и его метку страны, состояние автоподключения, исключения приложений и IP, списки источников и их расписание. Формат использует AES‑256‑GCM, случайные соль и nonce и PBKDF2‑HMAC‑SHA256 с 600 000 итераций. Для восстановления выберите файл, введите пароль, проверьте состав копии и подтвердите замену настроек при отключённом VPN.

## Диагностика сети

«Диагностика сети» выполняет до трёх проб по каждому доступному маршруту. Она показывает ICMP Ping, среднее абсолютное изменение RTT между ответами и долю отправленных проб без ответа за 900 мс. Сервер профиля проверяется напрямую. Для 1.1.1.1 и 9.9.9.9 проверяются прямой маршрут и маршрут через VPN с учётом настроенных исключений. Для тестовых адресов при необходимости отдельно отображается время установки TCP-соединения на порту 443 и доля неудачных подключений.

Автоизмерения выполняются раз в 30 секунд при активном VPN и открытом экране диагностики. История хранит 20 последних серий в памяти. Android или сеть могут ограничивать ICMP. В этом случае интерфейс отображает отсутствие результата или ответов для этого протокола.

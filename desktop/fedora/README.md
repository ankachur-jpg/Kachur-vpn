# Kachur VPN для Fedora — начальный прототип

Это отдельное настольное приложение в общем репозитории Kachur VPN.
Android-приложение и его настройки не затрагиваются. Текущая ветка —
**прототип 0.1**, а не готовый Linux VPN-клиент 1.0.

## Технологии

- Fedora Workstation, GNOME, GTK4 + libadwaita, Python 3 (PyGObject).
- Системный движок AmneziaWG: `awg`, `awg-quick`, при необходимости `amneziawg-go`
  в userspace-режиме. Нельзя использовать обычный WireGuard для профиля AWG 2.0.
- Чтение наличия интерфейса и байтов через `/sys/class/net`, без root.
- Полномочия администратора запрашиваются **только** при нажатии
  «Включить»/«Отключить», через `pkexec`; GUI никогда не запускается как root.
- Подключение из существующего root-owned профиля
  `/etc/amneziawg/amn0.conf`, с правами доступа только для root.
  Приложение в этой версии не импортирует профиль и не создаёт его.

## Запуск на Fedora

Установить зависимости интерфейса (команда не устанавливает движок VPN):

```bash
sudo dnf install python3-gobject gtk4 libadwaita polkit
```

После установки и отдельной настройки совместимого Linux-движка AWG:

```bash
bash desktop/fedora/run.sh
```

При необходимости в поле окна заменить `amn0` на имя настроенного
интерфейса (без `.conf`). Если `awg-quick` отсутствует или требует
особых параметров, приложение покажет ошибку — оно не пытается запускать
другой протокол или изменять сетевые настройки автоматически.

Запуск тестов без графической оболочки и root:

```bash
PYTHONPATH=desktop/fedora python3 -m unittest discover -s desktop/fedora/tests -v
```

## Ограничения 0.1

**Это рабочий прототип интерфейса, но не полноценный порт Android-приложения.**
Включение/выключение возможно лишь для уже установленного и совместимого
`awg-quick`. Совместимость конкретного сервера, прав polkit, DNS и маршрутов
на Fedora 45 ещё требуется проверить на реальном устройстве. Отображение
активного интерфейса не подтверждает успешный handshake: его время
показывается, только если системная утилита отдаёт статистику без повышения
привилегий.

В прототипе **ещё нет**: импортирования профилей, автоматического
переподключения, исключений приложений, импорта/автообновления JSON IP,
шифрованных резервных копий, проверки Ping, плитки в панели GNOME и RPM.

## Следующие этапы

1. Безопасный системный сервис с узкими D-Bus/Polkit правами:
   импорт/хранение нескольких профилей, безопасный запуск AWG 2.0
   в userspace-режиме без DKMS и без отключения Secure Boot.
2. Состояния handshake, статистика, восстановление при смене Wi-Fi,
   сохранение выбора сервера, диагностика.
3. Раздельная маршрутизация по IP/CIDR, включая существующие JSON-файлы,
   RIPEstat и пользовательские исключения; DNS и IPv6 должны быть проверены.
4. Исключения отдельных приложений (cgroup v2/policy routing;
   учитывать Flatpak). Не применять рискованные правила без тестов.
5. GNOME Quick Settings extension с переключателем и уведомления,
   повторное использование ротвейлера на значке, RPM, автотесты Fedora.

Все операции с реальным VPN должны быть доступны для отмены. Не сохранять
секретные конфигурации в логах и не публиковать их в Git. Kill Switch не нужен.

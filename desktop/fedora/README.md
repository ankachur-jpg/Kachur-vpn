# Kachur VPN для Fedora 45

Настольный клиент GNOME использует GTK4, libadwaita и установленный
движок AmneziaWG. Подключение доступно вручную или автоматически при входе
в GNOME, если включён установленный автозапуск.

## Установка

Из корня репозитория в ветке `feat/fedora-desktop`:

```bash
sudo dnf install python3-gobject gtk4 libadwaita polkit iproute iptables-nft curl
sudo install -Dm755 desktop/fedora/kachur-vpn-helper /usr/local/libexec/kachur-vpn-helper
sudo install -Dm755 desktop/fedora/kachur-vpn-network.py /usr/local/libexec/kachur-vpn-network
sudo bash desktop/fedora/install-polkit.sh
bash desktop/fedora/install-desktop.sh
```

Установщик Polkit разрешает только фиксированные операции подключения и отключения Kachur без повторного ввода пароля в активном локальном сеансе текущего пользователя. Он не отключает Polkit и не разрешает запуск произвольных команд. Импорт профиля и JSON-списка по-прежнему требует административной авторизации.

Последняя команда устанавливает ярлык **Kachur VPN** в меню приложений GNOME и автозапуск в `~/.config/autostart`. При входе в GNOME окно Kachur открывается через 12 секунд и пытается подключить туннель без пароля. Если уже работает AmneziaVPN (интерфейс `amn0`), автоподключение пропускается: два туннеля одновременно не запускаются. При временной недоступности сети выполняются до трёх попыток. Автозапуск можно отключить удалением файла `~/.config/autostart/com.kachur.vpn.Fedora.desktop`.

Нужны совместимые `awg`, `awg-quick` и, для userspace-режима,
`amneziawg-go`. На Fedora для DNS используется работающий `systemd-resolved`.
Поддерживается профиль `/etc/amnezia/amneziawg/kch0.conf` с владельцем root,
правами 600, адресом IPv4 и `0.0.0.0/0` в AllowedIPs. Существующий профиль
можно использовать непосредственно. При импорте через окно предыдущая
версия сохраняется в `kch0.conf.backup` с правами 600.


## Импорт JSON со списком IP для обхода VPN

В приложении есть кнопка **Импортировать список IP (.json)**. Файл должен иметь формат:

```json
{
  "version": 1,
  "bypass_vpn": [
    "203.0.113.10/32",
    "198.51.100.0/24",
    "2001:db8:1234::/48"
  ]
}
```

Это демонстрационные адреса из документационных диапазонов — замени их своими IP-адресами. Можно указывать отдельный IPv4/IPv6-адрес или сеть CIDR. Допускается до 100 записей; дубликаты нормализуются. Маршрут по умолчанию (`0.0.0.0/0` и `::/0`), multicast, loopback и неопределённые адреса запрещены.

Адреса из `bypass_vpn` направляются напрямую через основную таблицу Fedora, минуя Kachur; весь остальной трафик идёт через VPN. Исключения применяются при следующем подключении, поэтому импорт доступен только при выключенном Kachur. IPv6-исключения требуют включённого IPv6 в Fedora. Список хранится в root-owned файле `/etc/kachur-vpn/bypass.json`; предыдущая версия сохраняется в `bypass.json.backup`. Сам список не содержит ключей VPN и доступен приложению для отображения.

Если у AmneziaVPN остались старые OUTPUT-якоря KillSwitch, Kachur добавляет в собственную временную цепочку только адреса из импортированного списка и маршрут к своему зашифрованному серверному endpoint. Собственные цепочки Amnezia не редактируются. Все временные правила обхода удаляются при отключении Kachur или аварийной очистке systemd.

## Переключение с AmneziaVPN

1. Отключите AmneziaVPN штатной кнопкой в её окне. Kachur не допускает
   одновременную работу: если интерфейс `amn0` существует, подключение
   будет остановлено.
2. Нажмите **Включить VPN** в Kachur. Служба проверит маршрут IPv4, HTTPS
   и DNS. Если после отключения Amnezia остались переходы
   `OUTPUT -> amnvpn.anchors`, Kachur не удаляет и не меняет цепочки Amnezia.
   Вместо этого он временно создаёт собственную цепочку `KACHUR_OUT`
   перед правилами OUTPUT. Она разрешает только трафик через интерфейс
   `kch0` и UDP-пакеты с меткой транспорта AWG к IP-адресу и порту VPN-сервера
   через физический сетевой интерфейс. Остальной трафик возвращается
   в исходные правила firewall и продолжает ими фильтроваться.
3. Чтобы вернуться к AmneziaVPN, нажмите **Отключить VPN** в Kachur
   и дождитесь сообщения об отключении. Kachur удалит только собственную
   цепочку `KACHUR_OUT`, интерфейс, маршруты и DNS. После этого подключите
   AmneziaVPN. Если AmneziaVPN запустится во время сеанса Kachur,
   служба Kachur обнаружит `amn0` и начнёт откат своего сеанса.

Исходные правила AmneziaVPN и firewalld не удаляются и не редактируются.
Временная цепочка Kachur снимается при штатном отключении и через
`ExecStopPost` systemd при аварийном завершении рабочего процесса.
Если отключение было прервано, повторная команда отключения очищает только
цепочку `KACHUR_OUT` и зарезервированные маршруты Kachur. Во время сеанса
используется собственная таблица маршрутов Kachur и метка транспорта AWG. `Table=off` и `FwMark` в исходном
профиле не влияют на эту таблицу. Kachur передаёт `awg-quick` временную
копию с выключенной автоматической маршрутизацией и сам настраивает
маршруты и DNS. Исходный профиль остаётся на диске без изменений.

DNS берётся из профиля. При отсутствии подходящих адресов используются
`1.1.1.1` и `1.0.0.1`. DNS применяется к `kch0` через systemd-resolved.
IPv6 проходит через туннель, если в профиле есть адрес IPv6 и `::/0`.
Для профиля без IPv6-маршрута внешний IPv6 блокируется на время сеанса.
Подключение обычных приложений после остановки Kachur снова определяется
настройками Fedora. Постоянный KillSwitch Kachur не предусмотрен.

## Автономная проверка

Проверка запускается из окна **Kachur VPN** кнопкой **Автономный тест с отчётом**.
Сначала прочитайте диалог-предупреждение. Если AmneziaVPN ещё включена, не
подтверждайте запуск. Kachur сам не отключает AmneziaVPN и не редактирует её
собственные цепочки firewall. Если остались OUTPUT-якоря, на время теста
создаётся отдельная цепочка `KACHUR_OUT` с разрешениями только для `kch0`
и зашифрованного UDP-трафика к VPN-серверу.

Порядок безопасного теста:

1. Пока ChatGPT доступен через AmneziaVPN, откройте Kachur VPN и оставьте окно открытым.
2. Отключите AmneziaVPN штатной кнопкой в её окне.
3. В Kachur нажмите **Автономный тест с отчётом** и подтвердите запуск.
4. Дождитесь результата. Тест поднимает временный `kch0`, проверяет HTTPS
   с проверкой сертификата, DNS через туннель и HTTPS по имени через
   системный DNS. Затем он удаляет созданные интерфейс, маршруты и DNS.
5. Снова включите AmneziaVPN. После восстановления доступа к ChatGPT отправьте
   файл `~/kachur-offline.*.log`, путь к которому покажет Kachur.

Systemd ограничивает время тестового сеанса 95 секундами и запускает очистку
отдельно от процесса теста, в том числе при аварийном завершении приложения.
Если тест прервался или Kachur сообщил об ошибке отката, не включайте AmneziaVPN
до проверки состояния службы:

```bash
systemctl is-active kachur-vpn.service
```

`inactive` означает, что служба остановлена. При `active` дождитесь завершения;
при `failed` проверьте журнал:

```bash
sudo journalctl -u kachur-vpn.service -n 30 --no-pager
```

Если окно закрыли до записи отчёта, этапы проверки и отката доступны
в журнале службы по команде выше.

В локальный отчёт записываются только этапы проверки и безопасные сообщения
об ошибках. Содержимое профиля, ключи и ответ HTTPS не сохраняются.
